# Week 3 Assignment - JavaScript Fundamentals (Part 1)

This repository contains all 6 tasks completed for Week 3 of the Web Development Internship, focusing on core JavaScript syntax, variables, data types, operators, conditional structures, and control loops.

## 📁 File Structure

- `task1.html` & `task1.js` - Basic syntax, logging, and script linkage
- `task2.html` & `task2.js` - Variable scopes, data types, and typeof checks
- `task3.html` & `task3.js` - Arithmetic, assignment, comparison, and logical operators
- `task4.html` & `task4.js` - Control flow using if-else and nested conditionals
- `task5.html` & `task5.js` - Loops (for, while, do-while) and iteration tasks
- `task6.html` & `task6.js` - 5 practice programs combining all concepts

## 🚀 How to Run

1. Clone or download this repository.
2. Open any `.html` file in your preferred browser.
3. Open Developer Tools (`F12` -> `Console`) to view program outputs.
